# TAPIS DIGITECH Tools Architecture

## Launch order
### 1. AI ROI Calculator
Inputs: employees, monthly cost, repetitive hours, working days, automation potential.
Outputs: annual hours affected, estimated opportunity range, recommended automation category.
CTA: Get My Automation Roadmap.

### 2. AI Readiness Assessment
10–15 business questions. Output a readiness score, recommended use cases and next step.

### 3. Website Cost Calculator
Inputs for project type, pages, ecommerce, AI, dashboard, integrations and timeline. Output a transparent estimate range and recommended delivery approach.

## Principles
- Every tool must be genuinely useful without mandatory lead capture.
- Tool pages must link to relevant services and educational content.
- Do not promise precise savings or pricing as guarantees.
- Track tool start, completion and CTA conversion events.
